# Fleet & Machinery Desktop v0.4.0
รุ่นทดสอบ Desktop Offline ที่ใช้ Requirement ของ v0.13.4 เป็นขั้นต่ำ และต่อยอด Usage/Maintenance/Fuel ตามที่ตกลงกัน

ฟังก์ชันหลัก: Asset 90 รายการ, Asset Profile, Edit fields ครบ, Photo Gallery, Documents + Renewal/Version, Master Data, Owner Registry, Person/User/Role/Data Scope, Audit, Usage Request→Print→Approval→Assignment→Return, Maintenance/PM/Incident, Fuel/Expense, Reports, JSON + SQLite Backup/Restore.

Build: `npm install && npm run check && npm test && npm run build:win`
