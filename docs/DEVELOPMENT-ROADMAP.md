# Development Roadmap

## v0.1.x Foundation
Asset, Owner Registry, Person/User, SQLite migration, Usage Request skeleton, Meter, Audit, Backup, HR integration foundation.

## v0.2.x Usage Workflow
Printable request/approval/return document, approval capture, assignment, conflict/warning checks, checkout/return, status history.

## v0.3.x Maintenance
Repair request, Work Order, PM schedule, vendor, maintenance item, attachment, cost posting.

## v0.4.x Fuel & Cost
Fuel transaction, meter validation, expense ledger, cost per km/hour, reimbursement for private employee assets.

## v0.5.x Offline Exchange & Security
Site/Device provisioning, Role/Permission/Data Scope enforcement, signed Access/Master/Data Packages, conflict queue, encrypted backup.
